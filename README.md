# Patent classifier based on RoBERTa model
A fine-tuned classifier based on RoBERTa for detecting AI involvement in patent claim.   Given a patent claim, the model classifies it as human written, AI-generated, or refined.  
Trained on 2,000 US utility patent claims from Google Patents Public Datasets, with AI counterparts generated using Gemini 2.5 Flash. Achieves 91% test accuracy on three-class classification.  

## General_patent
### Datasets
Human written patent claims were extracted from Google Patents Public Datasets on BigQuery (US utility patents, publication date 2018-02).  
AI generated claims were produced using Gemini-2.5-Flash, prompted with patent titles to write claim 1.  
Refined claims were generated by feeding AI-generated claims back to Gemini-2.5-Flash with instructions to make minor edits while preserving 80-90% of the original text.  
Each category contains 1000 samples, split into train/validation/test sets.  

### Experiments
Experiment 1: Length-only baseline   
Random Forest using text length as feature. Accuracy: 37%, confirming that text length alone cannot distinguish the three categories.  
Experiment 2: 3 features baseline.  
Random Forest using perplexity, burstiness, and semantic shift. Accuracy: 50%. Feature directions matched theoretical expectations but insufficient for reliable classification.  
Experiment 3: RoBERTa fine-tuning. 
Fine-tuned RoBERTa-base with truncation at 512 tokens for 4 epochs. Accuracy: 91%. Human claims were classified with perfect precision and recall; the primary challenge was distinguishing AI-generated from AI-refined claims.
